## Setup
    pip install -r requirements.txt

## Reproduce every table and figure (one command)
    python run_all.py
Writes results/run_all_output.txt (all tables) and figures/*.png. Every output carries the member stamp.
The LLM part needs a Gemini key and is read from results/part_d.json. To (re)run it:
    $env:GEMINI_API_KEY="..."      (PowerShell)
    $env:GEMINI_MODEL="gemini-3.5-flash-lite"
    python llm_agent.py            (or: python llm_agent.py --only=2,7  to rerun some requests)
    python llm_agent.py --mock     (pipeline test only, not for the report)

## UI
    streamlit run ui.py

## Files
- config.py: members, stamp, instance loading, live-changeable parameters
- world.py: grid, vectorised cost map, tunnels, wind drift, slip, stochastic step
- search.py: BFS, UCS, DLS, IDS, Greedy, A* (from scratch) on (position, delivered-set)
- heuristics.py: own admissible heuristic (exact distances + MST), baselines, consistency check
- game.py: reduced game (7x7 window), Minimax, Alpha-Beta with own move ordering, evaluation functions
- simulator.py: full games with slip/wind and replanning counters
- run_games.py: node counts, weight tuning, 30 games, replanning statistics (Part C)
- dispatch_tools.py, llm_agent.py: LLM dispatcher, tools, validation layer, 20 requests (Part D)
- experiments.py: 30 seeded scenarios, CIs, ablation, failure analysis
- viz.py, ui.py, run_all.py: plots, Streamlit UI, one-command reproduction
- test_search.py: Part B tables on the instance

## Live changes in the viva

(or World(overrides={"slip_probability": 0.5})) and rerun python run_all.py.
